# SAFETY.md — اقرأ هذا قبل التشغيل / Read before running

> **الحالة:** Developer Preview. الأداة تتطور بسرعة وقد تتغير الواجهات.

## المبادئ / Principles

1. **محلي أولاً (Local-first).** `runtime.local_only = true` افتراضياً. لا تغادر
   بياناتك الجهاز إلا عند تفعيلك لتكامل خارجي (مثل Zapier) أو أداة الشبكة `http`.
2. **المفاتيح في البيئة فقط (Keys in env only).** لا تُخزَّن مفاتيح API داخل
   `smartcrew.config.toml`. الملف يشير فقط إلى اسم متغير البيئة عبر `api_key_env`.
   استخدم ملف `.env` (غير متتبَّع في Git).
3. **الذاكرة المعرفية على القرص (Knowledge memory on disk).** تُخزَّن في
   `.smartcrew/memory/*.jsonl` بصيغة نصية قابلة للفحص والتدقيق، ومستقلة عن أي
   مزوّد نموذج. هذا المجلد مستثنى من Git افتراضياً.
4. **تأكيد العمليات الحساسة.** الأوامر المدمِّرة، والكتابة خارج جذر المشروع،
   وأي خروج شبكي (egress) تتطلب تأكيداً — انظر `[safety]` في التكوين.

## ما الذي يضمنه التبديل بين النماذج / Model-switching guarantees

- قبل كل تبديل تُؤخذ **لقطة (snapshot)** كاملة للذاكرة (`persist_memory_on_switch`).
- بعد التبديل يُعاد **حقن السياق المعرفي** في النموذج الجديد
  (`rehydrate_memory_on_switch`) بحيث لا تفقد القرارات أساسها.
- يُسجَّل **أي نموذج اتخذ أي قرار** (`track_provenance`) في طبقة `decisions`.

## حدود ومخاطر / Limits & risks

- منفّذ الأدوات (`shell`) مقيّد بقائمة `allow`؛ راجعها قبل السماح بأوامر جديدة.
- لا تضع أسراراً في طبقات الذاكرة — قد تُحقن ضمن سياق النموذج.
- التضمين المتجهي (`[memory.embedding]`) اختياري ومعطّل افتراضياً.
- هذا مشروع مرجعي/تعليمي: راجع الكود قبل استخدامه في الإنتاج.

## الإبلاغ عن مشكلة / Reporting

افتح Issue في المستودع مع خطوات إعادة الإنتاج، دون تضمين أي مفاتيح أو بيانات حساسة.
